# dbt-sentinel

An AI-grounded data-quality companion for dbt. When a dbt test fails, dbt tells you
*what* failed — dbt-sentinel reads the run artifacts and tells you *why*, in plain
English, grounded in the actual schema and failing rows, then tracks failures over time.
